# 🃏 Белот — счётчик очков

Простое веб-приложение для подсчёта очков в карточной игре **белот**. Поддерживает два режима:

- **3 игрока** — каждый играет сам за себя;
- **4 игрока (2×2)** — две команды по два человека.

Приложение — один файл `index.html` без зависимостей и сборки. Откройте его в любом браузере (удобно с телефона за игровым столом). Текущая партия сохраняется в браузере (localStorage), так что случайно закрытая вкладка не потеряет счёт.

## Возможности

- Выбор режима: втроём или командами 2×2
- Имена игроков / названия команд
- Настраиваемая цель партии: 151, 301, 501, 1001 или своё значение
- Запись очков по раздачам с быстрыми кнопками для объявлений (+20, +50, +100)
- История раздач с нарастающим итогом
- Отмена последней раздачи
- Автоматическое определение победителя

## Как пользоваться

1. Откройте `index.html` в браузере.
2. Выберите режим, введите имена и цель партии, нажмите «Начать игру».
3. После каждой раздачи введите очки каждой стороны (со всеми объявлениями и бонусами) и нажмите «Записать раздачу».
4. Когда кто-то набирает целевую сумму — приложение объявляет победителя.

## Правила белота (краткая справка)

### Общее

Играют колодой в 32 карты (от семёрок до тузов). Стоимость карт:

| Карта | Козырь | Не козырь |
|-------|--------|-----------|
| Валет | **20** | 2 |
| Девятка | **14** | 0 |
| Туз | 11 | 11 |
| Десятка | 10 | 10 |
| Король | 4 | 4 |
| Дама | 3 | 3 |
| 8, 7 | 0 | 0 |

Всего в раздаче **152 очка** за карты **+ 10 за последнюю взятку = 162**.

Обязательно ходить в масть; на козыря обязательно класть старшего козыря, если он есть («перебивать»).

### Объявления (комбинации)

| Комбинация | Очки |
|------------|------|
| Белот (король + дама козыря) | 20 |
| Терц (3 карты подряд одной масти) | 20 |
| Полтинник (4 подряд) | 50 |
| Сто (5 подряд) | 100 |
| Каре дам, королей, десяток или тузов | 100 |
| Каре девяток | 150 |
| Каре валетов | 200 |

### Белот на 4 игроков (2×2)

- Две команды по два игрока, партнёры сидят напротив.
- Каждому раздают по 8 карт, козырь определяется на торговле.
- Команда, взявшая козырь («играющая»), должна набрать больше очков, чем противник, иначе она «внутри» (bete) — все очки раздачи уходят сопернику.
- Если команда берёт **все** взятки — капот (обычно +90 или +100 бонусом, по договорённости).
- Партия обычно идёт до **151** (в короткой версии) или до **501/1001** очка.

### Белот на 3 игроков

- Каждый играет сам за себя.
- Из колоды обычно убирают одну семёрку (31 карта: 3×10 + 1 в прикуп) либо играют иным согласованным раскладом — по договорённости стола.
- Взявший козырь должен набрать не меньше трети очков раздачи (или больше каждого из соперников — в зависимости от варианта правил), иначе он «внутри».
- Остальные правила — стоимость карт, объявления, +10 за последнюю взятку — те же.

> Вариантов белота много (молдавский, болгарский, французский). Приложение не навязывает конкретный вариант — оно просто ведёт счёт: итоговые очки каждой раздачи вы вводите по своим правилам стола.
